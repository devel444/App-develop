# 양산이관 검증위원회 통합 관리 포털

내 PC에서 Python 서버를 띄우면 사내망 사용자가 브라우저로 접속해 쓰는 웹 포털입니다.
데이터와 첨부파일은 사내 공유폴더에 바로 저장됩니다. 프론트엔드는 외부 CDN 없이(폐쇄망 OK) 순수 HTML/CSS/JS로 만들었습니다.

## 1. 실행 방법 (Windows)

**추가 설치가 필요 없습니다.** 서버는 Python 표준 라이브러리만 쓰므로 pip 설치 과정이 없습니다.
회사 방화벽이 PyPI를 막아도 그대로 동작합니다.

1. Python 3.8 이상 설치 (설치 시 **Add python.exe to PATH** 체크)
2. `transfer_portal` 폴더의 **`run_server.bat` 더블클릭**
   - 브라우저가 `http://localhost:8000` 으로 자동으로 열립니다.
3. 다른 PC에서는 콘솔 창에 표시되는 주소 `http://<서버PC IP>:8000` 으로 접속합니다.
   - 접속이 안 되면 Windows 방화벽에서 **TCP 8000 인바운드**를 허용하세요.
4. 서버를 끄려면 콘솔 창을 닫습니다.

초기 관리자 비밀번호는 **`1234`** 입니다. 처음 접속한 뒤 [🔒 관리자 모드 → 비밀번호 변경]에서 반드시 바꾸세요.

### 숫자 대신 이름으로 접속하기
- 콘솔 창과 [관리자 모드 → 시스템 정보]에 **PC 이름 주소**(예: `http://PC이름:8000`)가 함께 표시됩니다. 다른 PC에서 이 주소가 열리면 IP 대신 써도 됩니다.
- `massportal` 처럼 **원하는 이름**으로 접속하려면 사내 DNS 에 이름을 등록해야 하므로 IT팀에 요청하세요. (예: "massportal → 서버PC IP 등록 요청")
- `:8000` 을 없애려면 `run_server.bat` 의 `PORTAL_PORT=8000` 을 `80` 으로 바꾸세요. 그 PC에서 80 포트를 이미 쓰는 프로그램이 없어야 합니다.
- [관리자 모드 → 포털 접속 주소] 칸은 **메일에 들어가는 링크만** 바꿉니다. 실제 접속 주소를 바꾸는 기능은 아닙니다.

### 자주 나오는 문제
| 증상 | 해결 |
|---|---|
| `Python 3 is not installed` | Python 설치 후 PATH 체크. 또는 `py` 런처가 있으면 자동으로 사용됩니다 |
| `포트 8000 를 열 수 없습니다` | 서버가 이미 켜져 있는지 확인(검은 창이 2개?) |
| 다른 PC에서 접속 불가 | 방화벽 TCP 8000 인바운드 허용, 서버 PC 절전 해제 |
| 저장소가 "로컬 폴백"으로 표시 | 탐색기에서 `\\10.150.6.49\...` 경로가 열리는지·쓰기 권한이 있는지 확인 |

## 2. 저장소 (공유폴더 연동)

| 우선순위 | 경로 |
|---|---|
| 1 | 환경변수 `PORTAL_DATA_DIR` (지정한 경우) |
| 2 | `\\10.150.6.49\전사혁신과제관리용_db\(기술혁신)_양산이관_검증위원회` |
| 3 | 위 경로에 쓸 수 없으면 자동 폴백: `./shared_data` |

현재 쓰고 있는 저장소는 사이드바 상단과 [관리자 모드 → 시스템 정보]에 표시됩니다.
로컬로 폴백된 상태라면 노란색 경고로 표시됩니다.

```
저장소/
├─ data.json              안건, 5단계 진행상태, 6대 부문 Risk 과제
├─ settings.json          관리자 비밀번호(해시), 알림 수신자, 주소록, SMTP, 팀 목록, 양산이관 기준 문구
├─ users.json             회원 (사번, 이름, 팀, 이메일, 비밀번호 해시, 승인 상태)
├─ attachments/{안건ID}/   신청·검토 첨부파일
├─ forms/                 표준 양식 자료실
└─ backups/               하루 1회 data.json 자동 백업(30일), 삭제된 첨부 보관
```

- **기존 HTML 대시보드 데이터 자동 이관**: 저장소에 `data.json` 이 없고 예전 `data.js` 가 있으면, 첫 실행 때 그 내용을 그대로 가져옵니다. 둘 다 없으면 샘플 5건을 만듭니다.
- 저장할 때마다 서버가 `data.json` 을 원자적으로(임시파일 → 교체) 기록합니다. 따라서 예전처럼 data.js 를 다운로드해서 손으로 덮어쓸 필요가 없습니다.
- 두 사람이 같은 안건을 동시에 고치면, 나중에 저장하는 사람에게 **충돌 확인**이 뜹니다. 덮어쓸지, 최신 내용을 다시 불러올지 고를 수 있습니다.
- 다른 사람이 수정한 내용은 30초마다 자동으로 반영됩니다.

## 3. 메뉴 구성

| 메뉴 | 주요 기능 |
|---|---|
| 📊 대시보드 | KPI 4종(전체 안건 / 🚨지연 안건 / 🚨지연 과제 / ⏳조치 대기), **📌 지금 조치가 필요한 항목**(늦은 순, ✉️ Remind), 단계별 진행 현황(지연 표시), 📅 향후 2주 일정. 비로그인은 KPI·단계 현황만 |
| 📋 양산이관 세부현황 | 구분·연도·상태·검색 필터, CSV 내보내기/업로드(UTF-8/EUC-KR 자동 감지), 상세 모달 |
| 🛠️ 보완 과제 현황 | 지연 과제를 맨 위에 표시(🚨 +N일), 등급·부문·상태 필터, 관리자는 진행중 ⇄ 완료 원클릭 전환 |
| 📝 양산이관 신청 | 개발팀 회원만 보임, 요청자 정보 자동 입력, 첨부 드래그 앤 드롭, 신청하면 간사·팀장에게 알림 메일 자동 발송 |
| 📖 양산이관 기준 | 프로세스 플로우차트, NP/SP/기술 기준과 6대 부문 체크리스트(관리자 수정 가능), 표준 양식 자료실 |
| 🔒 관리자 모드 | 접수 승인, 알림 수신자·SMTP 설정과 테스트, 부문별 주소록, 검토 요청 메일 작성, 백업, 비밀번호 변경 |

상세 모달에서는 다음을 할 수 있습니다.
- 5단계 일정 수립과 완료를 따로 처리합니다.
- **⚡ 특이사항 없음**: 2~4단계를 생략합니다. 다시 누르면 원래대로 돌아갑니다.
- **📌 소위 전결**: 3·4단계를 생략합니다. 다시 누르면 원래대로 돌아갑니다.
- 검토 요청 메일 패널과 6대 부문 Risk 테이블을 씁니다.

## 4. 단계별 목표일 · 지연 · 연장

| 단계 | 목표일 (영업일, 주말·등록 휴일 제외) |
|---|---|
| 1. 전문소위원 검토 | **접수 승인일** + 5일 |
| 2. 검증소위원회 | 1단계 완료일 + 7일 |
| 3. 전문위원 검토 | 2단계 완료일 + 7일 |
| 4. 검증위원회 | 3단계 완료일 + 7일 |
| 5. 최종승인 | 직전(생략 제외) 단계 완료일 + 7일 — 패스트트랙이면 1단계, 소위 전결이면 2단계 완료일 기준 |

- 현재 단계의 목표일이 지났는데 완료되지 않았으면 **🚨 지연 +N일**로 표시됩니다(세부현황 목록, 상세, 상태 필터 "단계 지연").
- 목표일은 **관리자만** 현재 단계 카드의 [⏰ 목표일 연장]으로 바꿀 수 있고, **사유가 필수**입니다. 변경 이력(이전→새 날짜, 사유, 일시)이 남습니다.
- [완료 처리]를 누르면 그날이 **완료일**로 기록되고 다음 단계 목표일이 자동 계산됩니다. 완료일은 관리자가 수정할 수 있습니다.
- 공휴일·회사 휴무일은 [관리자 모드 → 📅 휴일]에 등록합니다.
- 이전 버전 데이터는 자동 변환됩니다(완료된 단계의 날짜 → 완료일, 진행 중 단계의 날짜 → 목표일).

## 5. 안건 · 팀별 검토 의견 · 보완 과제

```
📁 안건 (양산이관 신청 1건) ─ 제품 구분(300mm/200mm × PW/EPI) · 5단계 진행 · 단계별 목표일·지연
 ├─ 📝 팀별 검토 의견 (선정된 검토 팀 × 1줄) ← 해당 팀 회원(팀장·Pro 누구나) 작성: ✅ OK(의견) / ⚠️ Risk(+ Risk 목록)
 └─ 🛠 보완 과제 (T01, T02 …)               ← 간사가 2단계에서 Risk 마다 [과제 등록] 또는 [수용(사유)] 결정
```

### 검토 팀 자동 선정 (제품 구분 매트릭스)
- 신청 시 **제품·기술 안건 모두** 구경(300mm/200mm)과 PW/EPI 를 반드시 선택합니다.
- 접수 승인 시 아래 기본 매트릭스대로 검토 팀이 자동 선정됩니다. (관리자 모드 → **검토 팀 매트릭스**에서 수정 가능)

| 구분 | 검토 팀 |
|---|---|
| 공통(모든 제품) | 생산성: 제조운영팀 · 손익: 효율혁신팀 |
| 300mm PW | 종합공정2팀 / 장비기술1·2·3팀, Metrology기술팀 / GR기술2팀, LS공정기술1·2·3팀, 오염제어기술팀 / LS제조1·2·3팀 |
| 300mm EPI | 300mm PW + EPI기술1·2팀, LS제조4팀 |
| 200mm PW | 종합공정1팀 / MS장비기술팀, Metrology기술팀 / GR기술1팀, MS공정기술팀, 오염제어기술팀 / MS제조1·2팀 |
| 200mm EPI | 200mm PW + EPI기술1·2팀, LS제조4팀 |

- **기술** 안건은 자동 선정하지 않습니다. 간사가 안건 상세 아래쪽 **검토 팀 선정 · 검토요청 메일** 패널에서 공정에 맞게 직접 고릅니다.
  (구경·PW/EPI 기본 팀을 [기본 팀 불러오기]로 참고 삼아 불러온 뒤 빼거나 더할 수 있습니다.)
- [3] 검토 의견은 팀이 1~2개인 부문(품질/수율·생산성·손익)을 한 줄에 나란히, 팀이 많은 부문(장비·Process·제조)은 팀 줄을 2~3열로 나눠 보여 줍니다(화면 폭에 맞춰 자동).
- 같은 패널에서 팀을 추가/제외하고, 선정된 팀 회원에게 바로 검토요청 메일을 보냅니다(기본 선택: 팀장).
- 예전 안건은 제품 구분이 비어 있습니다. 상세에서 제품 구분을 고른 뒤 [기본 팀 적용]을 누르면 매트릭스대로 선정됩니다.
- 예전 부문 검토 의견은 "(기존) 부문명" 줄로 그대로 보존됩니다.

### 팀별 검토 작성
- 한 줄에 [✅ OK] [⚠️ Risk] 작은 버튼 (✅ OK = 이상 없음). OK 는 의견을 적을 수 있고, 비워 두면 **"특이사항 없음"** 으로 저장됩니다.
- 해당 팀 회원이면 팀장·Pro 상관없이 작성할 수 있고, 임시 저장/작성 완료 이력(팀·이름·직책·시각)이 남습니다.
- 작성 완료 후 수정은 관리자가 [다시 열기]로 풀어 줍니다.

| 규칙 | 내용 |
|---|---|
| 1단계 완료 | 선정된 팀 모두 [작성 완료] 확인 (미완료 팀이 있으면 확인 창) |
| ⚡ 패스트트랙 | 선정된 팀이 모두 '✅ OK' 일 때만 가능 |
| 2단계 완료 / 📌 소위 전결 | 결정 대기 Risk 가 없어야 함 |
| 5단계 최종승인 | 중요도 **상** 과제가 남아 있으면 불가 · **중·하**만 남으면 **조건부 승인**(잔여 과제 계속 추적) |

- 과제는 중요도·보완 방안·담당조직·담당자(회원 선택 또는 이메일 직접 입력)·목표일(연장은 사유 필수)·상태를 관리합니다.
- 위원회가 결정한 Risk 는 팀에서 수정·삭제할 수 없습니다(결정 취소는 관리자만).
- 엑셀(Risk 상세) 내보내기/업로드는 새 형식(제품구분·검토팀·의견 열)과 예전 형식을 모두 지원합니다.

### 🗓 2단계·4단계 회의 차수 (1차·2차…)와 회의록
- 안건 상세 [2] 단계 표 아래에 **2단계 검증소위원회 / 4단계 검증위원회 회의** 칸이 있습니다.
- 관리자가 [+ n차 회의 추가] → 회의일·결과(통과 / 조건부 통과 / 재심의 / 보류)·요약 입력 → [📤 회의록]으로 파일 첨부. 입력하면 바로 저장됩니다.
- 회원은 회의 이력과 회의록을 열람·다운로드할 수 있습니다. 회의록 파일은 `attachments/<안건ID>/minutes/` 에 저장됩니다.
- 차수 삭제는 마지막 차수부터 가능하며, 지운 회의록은 `backups/deleted_attachments/` 로 옮겨집니다.
- 재심의로 일정이 밀리면 해당 단계의 [⏰ 목표일 연장](사유 필수)으로 조정합니다.

### ⏳ 장기 과제
- 안건 **발제일 + 3개월**이 지났는데 완료되지 않은 보완 과제는 '⏳ 장기 n개월+' 로 표시됩니다.
- 대시보드 '지연 과제' 카드의 [⏳ 장기 n]을 누르거나, 보완 과제 현황에서 [⏳ 장기 과제] 필터로 모아 볼 수 있습니다.

### ✉️ Remind 메일 (관리자)
| 대상 | 받는 사람 | 버튼 위치 |
|---|---|---|
| 검토 미작성 팀 | 해당 팀의 승인된 회원 · 참조: 간사 (회원이 없는 팀은 보낼 수 없음 → 가입 필요) | 대시보드 조치 목록, 안건 상세 [3] 팀 줄 |
| 과제 지연/진행 확인 | 과제 담당자 이메일 · 참조: 간사 | 대시보드 조치 목록, 안건 상세 [4] 과제 |

- 보내기 전에 제목과 받는 사람을 확인 창으로 보여 줍니다. 보낸 기록(횟수·최근 날짜)이 버튼 옆에 남습니다.
- 과제 담당자 이메일이 없으면 버튼이 '담당자 미지정'으로 비활성화됩니다.

## 7. 메일

**Outlook 자동 발송 (Outlook 2016/2019/365 데스크톱 모두 지원)**
- 서버 PC에서 **Outlook 을 켜 둔 상태**여야 합니다. 포털은 실행 중인 Outlook 에 연결해 메일을 보냅니다.
- 회사 PC 설정 때문에 서버가 '관리자 권한'으로 실행되어도 괜찮습니다. Outlook 연결이 막히면(0x80080005) **탐색기를 통해 일반 권한 작업으로 자동 우회**합니다. 이때 작은 창이 잠깐 깜빡일 수 있습니다.
- [관리자 모드 → ⚙️ 메일 발송 설정]에서 Outlook 연동 방식, Outlook 실행 여부, 서버 실행 권한, Python 경로를 확인할 수 있습니다.
- Outlook 이 계속 안 되면 IT팀에 사내 SMTP 서버 주소를 받아 SMTP 설정을 쓰세요(Outlook 실패 시 자동으로 SMTP 사용).

**신규 신청 알림 (자동 발송)**
- 서버 PC의 Outlook으로 먼저 보냅니다. pywin32가 없으면 Windows 기본 PowerShell로 Outlook을 제어합니다. Outlook은 클래식 버전이어야 하고, '새 Outlook'은 연동되지 않습니다. 실패하면 `settings.json` 의 SMTP로 보냅니다.
- 발송에 실패해도 안건은 정상 등록됩니다. 발송 결과는 상세 모달과 관리자 화면의 '알림메일' 칸에 표시됩니다.
- 수신자는 [관리자 모드 → 신규 신청 알림 수신자]에서 등록합니다. 처음에는 비어 있어서 '발송 안 함'으로 기록됩니다.

**검토 요청 메일 ([✉️ 검토 요청 메일 작성창 열기])**
- **서버 PC에서 접속한 경우**: Outlook 새 메일 창이 바로 뜹니다(`mail.Display()`).
- **다른 PC에서 접속한 경우**: `X-Unsent: 1` 이 붙은 `.eml` 초안이 내려받아집니다. 파일을 열면 Outlook 작성창이 뜨고 [보내기]만 누르면 됩니다.
- 받는 사람(;로 구분), 참조(간사·요청자), 제목, HTML 본문(요약, 안건 정보 표, 부문별 요청 표, 대시보드 링크)이 자동으로 채워집니다.
- 웹메일을 쓴다면 [📋 수신자 일괄 복사]와 [📋 메일 본문(서식 포함) 복사] 버튼을 쓰세요.
- 메일 본문의 접속 링크는 기본적으로 서버 PC IP로 만들어집니다. 고정 주소를 쓰려면 [관리자 모드 → 포털 접속 주소]에 지정하세요.

## 8. 보안 참고

- 관리자 비밀번호는 평문으로 저장하지 않습니다(PBKDF2-SHA256 + salt). 1분에 5회 이상 틀리면 잠시 잠깁니다.
- 관리자 인증은 서버가 발급한 세션 토큰으로 처리합니다. 브라우저 탭을 닫거나 서버를 재시작하면 다시 로그인해야 합니다.
- SMTP 비밀번호는 메일 발송에 필요하므로 `settings.json` 에 저장됩니다. 공유폴더 접근 권한을 관리 담당자로 제한하는 것을 권장합니다.
- 통신은 사내망 HTTP입니다. 외부망에 노출하지 마세요.

## 9. 파일 구조

```
transfer_portal/
├─ app.py               Python 서버 (표준 라이브러리만 사용: API, 저장소, 메일)
├─ templates/index.html SPA 골격
├─ static/style.css     스타일 (애니메이션, 반응형)
├─ static/app.js        화면 로직 (라우팅, 차트, 모달, CSV, 메일 패널)
├─ requirements.txt     필수 패키지 없음 (선택: pywin32)
└─ run_server.bat       더블클릭 실행
```

개발 및 테스트용으로 Linux나 Mac에서 실행할 수도 있습니다. 이때는 공유폴더 대신 자동으로 `./shared_data` 를 쓰고, Outlook 대신 SMTP를 씁니다.

```bash
python3 app.py
```
