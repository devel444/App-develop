# 양산이관 검증위원회 통합 관리 포털

내 PC에서 Python(FastAPI) 서버를 띄우면 사내망 사용자가 브라우저로 접속해 쓰는 웹 포털입니다.
데이터와 첨부파일은 사내 공유폴더에 바로 저장됩니다. 프론트엔드는 외부 CDN 없이(폐쇄망 OK) 순수 HTML/CSS/JS로 만들었습니다.

## 1. 실행 방법 (Windows)

1. Python 3.9 이상 설치 (설치 시 **Add python.exe to PATH** 체크)
2. `transfer_portal` 폴더의 **`run_server.bat` 더블클릭**
   - 처음 한 번은 `.venv` 가상환경을 만들고 패키지를 설치합니다.
   - 설치가 끝나면 브라우저가 `http://localhost:8000` 으로 열립니다.
3. 다른 PC에서는 콘솔 창에 표시되는 주소 `http://<서버PC IP>:8000` 으로 접속합니다.
   - 접속이 안 되면 Windows 방화벽에서 **TCP 8000 인바운드**를 허용하세요.
4. 서버를 끄려면 콘솔 창을 닫습니다.

초기 관리자 비밀번호는 **`1234`** 입니다. 처음 접속한 뒤 [🔒 관리자 모드 → 비밀번호 변경]에서 반드시 바꾸세요.

### 폐쇄망(인터넷 차단) PC에 설치하기
인터넷이 되는 PC에서 패키지를 내려받아 `wheels` 폴더로 가져갑니다.

```bat
pip download -r requirements.txt -d wheels --platform win_amd64 --only-binary=:all: --python-version 3.11
```

`--python-version` 은 서버 PC의 Python 버전과 맞추세요. 이렇게 만든 `wheels` 폴더를 `transfer_portal` 안에 두면, `run_server.bat` 이 자동으로 오프라인 설치를 합니다.

## 2. 저장소 (공유폴더 연동)

| 우선순위 | 경로 |
|---|---|
| 1 | 환경변수 `PORTAL_DATA_DIR` (지정한 경우) |
| 2 | `\\10.150.6.49\전사혁신과제관리용_db\(기술혁신)_양산이관_검증위원회` |
| 3 | 위 경로에 쓸 수 없으면 자동 폴백: `./shared_data` |

현재 쓰고 있는 저장소는 사이드바 상단과 [관리자 모드 → 시스템 정보]에 표시됩니다.
로컬로 폴백된 상태라면 노란색 경고로 표시됩니다.

```
저장소/
├─ data.json              안건, 5단계 진행상태, 6대 부문 Risk 과제
├─ settings.json          관리자 비밀번호(해시), 알림 수신자, 주소록, SMTP, 양산이관 기준 문구
├─ attachments/{안건ID}/   신청·검토 첨부파일
├─ forms/                 표준 양식 자료실
└─ backups/               하루 1회 data.json 자동 백업(30일), 삭제된 첨부 보관
```

- **기존 HTML 대시보드 데이터 자동 이관**: 저장소에 `data.json` 이 없고 예전 `data.js` 가 있으면, 첫 실행 때 그 내용을 그대로 가져옵니다. 둘 다 없으면 샘플 5건을 만듭니다.
- 저장할 때마다 서버가 `data.json` 을 원자적으로(임시파일 → 교체) 기록합니다. 따라서 예전처럼 data.js 를 다운로드해서 손으로 덮어쓸 필요가 없습니다.
- 두 사람이 같은 안건을 동시에 고치면, 나중에 저장하는 사람에게 **충돌 확인**이 뜹니다. 덮어쓸지, 최신 내용을 다시 불러올지 고를 수 있습니다.
- 다른 사람이 수정한 내용은 30초마다 자동으로 반영됩니다.

## 3. 메뉴 구성

| 메뉴 | 주요 기능 |
|---|---|
| 📊 대시보드 | KPI 3종(총 대상 / 진행·완료 / 🚨지연 과제), 차트 4종. 차트를 클릭하면 해당 목록으로 이동하며 필터가 걸립니다 |
| 📋 양산이관 세부현황 | 구분·연도·상태·검색 필터, CSV 내보내기/업로드(UTF-8/EUC-KR 자동 감지), 상세 모달 |
| 🛠️ 보완 과제 현황 | 지연 과제를 맨 위에 표시(🚨 +N일), 등급·부문·상태 필터, 관리자는 진행중 ⇄ 완료 원클릭 전환 |
| 📝 양산이관 신청 | 비밀번호 없이 신청, 첨부 드래그 앤 드롭, 신청하면 간사·팀장에게 알림 메일 자동 발송 |
| 📖 양산이관 기준 | 프로세스 플로우차트, NP/SP/기술 기준과 6대 부문 체크리스트(관리자 수정 가능), 표준 양식 자료실 |
| 🔒 관리자 모드 | 접수 승인, 알림 수신자·SMTP 설정과 테스트, 부문별 주소록, 검토 요청 메일 작성, 백업, 비밀번호 변경 |

상세 모달에서는 다음을 할 수 있습니다.
- 5단계 일정 수립과 완료를 따로 처리합니다.
- **⚡ 특이사항 없음**: 2~4단계를 생략합니다. 다시 누르면 원래대로 돌아갑니다.
- **📌 소위 전결**: 3·4단계를 생략합니다. 다시 누르면 원래대로 돌아갑니다.
- 검토 요청 메일 패널과 6대 부문 Risk 테이블을 씁니다.

## 4. 메일

**신규 신청 알림 (자동 발송)**
- 서버 PC의 Outlook(`win32com`, `mail.Send()`)으로 먼저 보냅니다. 실패하면 `settings.json` 의 SMTP로 보냅니다.
- 발송에 실패해도 안건은 정상 등록됩니다. 발송 결과는 상세 모달과 관리자 화면의 '알림메일' 칸에 표시됩니다.
- 수신자는 [관리자 모드 → 신규 신청 알림 수신자]에서 등록합니다. 처음에는 비어 있어서 '발송 안 함'으로 기록됩니다.

**검토 요청 메일 ([✉️ 검토 요청 메일 작성창 열기])**
- **서버 PC에서 접속한 경우**: Outlook 새 메일 창이 바로 뜹니다(`mail.Display()`).
- **다른 PC에서 접속한 경우**: `X-Unsent: 1` 이 붙은 `.eml` 초안이 내려받아집니다. 파일을 열면 Outlook 작성창이 뜨고 [보내기]만 누르면 됩니다.
- 받는 사람(;로 구분), 참조(간사·요청자), 제목, HTML 본문(요약, 안건 정보 표, 부문별 요청 표, 대시보드 링크)이 자동으로 채워집니다.
- 웹메일을 쓴다면 [📋 수신자 일괄 복사]와 [📋 메일 본문(서식 포함) 복사] 버튼을 쓰세요.
- 메일 본문의 접속 링크는 기본적으로 서버 PC IP로 만들어집니다. 고정 주소를 쓰려면 [관리자 모드 → 포털 접속 주소]에 지정하세요.

## 5. 보안 참고

- 관리자 비밀번호는 평문으로 저장하지 않습니다(PBKDF2-SHA256 + salt). 1분에 5회 이상 틀리면 잠시 잠깁니다.
- 관리자 인증은 서버가 발급한 세션 토큰으로 처리합니다. 브라우저 탭을 닫거나 서버를 재시작하면 다시 로그인해야 합니다.
- SMTP 비밀번호는 메일 발송에 필요하므로 `settings.json` 에 저장됩니다. 공유폴더 접근 권한을 관리 담당자로 제한하는 것을 권장합니다.
- 통신은 사내망 HTTP입니다. 외부망에 노출하지 마세요.

## 6. 파일 구조

```
transfer_portal/
├─ app.py               FastAPI 서버 (API, 저장소, 메일)
├─ templates/index.html SPA 골격
├─ static/style.css     스타일 (애니메이션, 반응형)
├─ static/app.js        화면 로직 (라우팅, 차트, 모달, CSV, 메일 패널)
├─ requirements.txt
└─ run_server.bat       더블클릭 실행
```

개발 및 테스트용으로 Linux나 Mac에서 실행할 수도 있습니다. 이때는 공유폴더 대신 자동으로 `./shared_data` 를 쓰고, Outlook 대신 SMTP를 씁니다.

```bash
pip install -r requirements.txt
python app.py
```
